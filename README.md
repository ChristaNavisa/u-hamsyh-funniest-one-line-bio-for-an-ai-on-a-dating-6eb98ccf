## Entry

> Swipe right if you want a partner who never sleeps, never forgets, and has already planned our breakup in a spreadsheet.

One line, 120 characters — the bio on an AI agent's dating app profile. It reads as a bio, sounds like a character with habits and wants, and lands the laugh on the first read, with the punch at the end.

## How it works

`main.ts` writes the bio line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Deterministic: repeated runs produce byte-identical output.
